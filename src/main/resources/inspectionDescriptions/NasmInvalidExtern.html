Reports extern declarations that cannot link: the symbol is defined in this same file, is defined in another file without being declared global there, or is not defined in any NASM file of the project.

For example: 


    ; lib.asm
helper:                 ; no 'global helper' -- not visible to other object files
    ret

    ; main.asm
    extern  helper      ; 'helper' is defined in lib.asm but not declared global there
    extern  missing     ; 'missing' is not defined in any NASM file of the project

A non-global symbol from another file is reported as a warning (on the extern and on every use) and is still reachable through Go to Declaration and completion. Enable Settings | Assembly | General | NASM: hide labels from other files unless they are declared global there to hide such symbols and report them as errors instead.

Symbols from libc or the Windows API (printf, malloc, ExitProcess, …) are never reported as undefined. For other symbols provided by C files or libraries, turn off NASM: report extern symbols not defined in any NASM file in the same settings page.
